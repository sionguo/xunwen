# 无 LLM 时的分类降级为 kNN 最近邻

分类主路径是 LLM 选择题 + 置信度分流。当 chat LLM 不可用而向量化端点可用时，分类降级为 kNN 最近邻投票：新文件向量在 KNN 索引中查最近的已分类文件，多数票定类别、平均相似度当置信度，走同一套阈值分流（自动 / 待审 / 待分类）。

理由：万份文档场景下「无 LLM 全部落待分类人工处理」的工作量不可接受；方案零新依赖（Lucene KNN + EmbeddingClient 均为现有资产），且天然延伸出现有「向量一致性钳制」的分层用法——kNN 高置信直通、低置信才问 LLM，可大幅降低全量入库的 LLM 调用量。

边界：类别树需先有种子（冷启动建树仍需 LLM 归纳或人工建）；连向量化也不可用时落待分类。
