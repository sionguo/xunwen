# xunwen（寻文）v1 规格说明书

> 本文档是 grilling 会话（2026-10-20）确认的设计共识的正式化。实现计划从本文档出发。

## 一句话

JavaFX 桌面工具：打开时监视用户的资料仓库，用可配置 LLM（默认本地 Ollama）将所有文件分类并把仓库重排为纯类别树，同时用 Lucene 建立「关键词 + 语义」混合索引供搜索。

## 核心流程

1. **注册仓库**：GUI 添加文件夹为仓库，多仓库并存、互不干扰
2. **冷启动**：扫描仓库抽样文档 → LLM 归纳生成 2 级类别树提案 → 用户增删改、批准 → 入树（存 `.xunwen/categories.yaml`）
3. **首次重排**（显式任务，进度可暂停）：全仓库文件提取内容 → LLM 分类（选择题）→ 按置信度分流移动 → 整个批次可一键回滚
4. **日常增量**：GUI 打开期间监视（WatchService 递归）+ 打开时处理积压；新文件走同样分流，高置信无感自动移动
5. **类别演化**：文件进不了现有类别 → LLM 提议新类别 → 相似拒绝 + 提议聚合 → 用户批准入树 → 相关文件归位

## 功能需求

- **FR-1 分类与置信度**：LLM 对每个文件输出 top 候选类别（从类别树中选择，不可自创）+ 候选分数 + 自报置信分 + 可选的新类别提议。合成置信度 = `self × (0.9 + 0.1 × margin)`，其中 `margin = s1 − s2`（仅一个候选时 margin = 1）；self 主导，候选差距只做微调（mimo 等模型候选分普遍偏高且接近，重罚 margin 会把高把握结果压进待审区）。**向量一致性钳制**：文件向量（bge-m3，已入库）与各类别向量（各级名称与描述 embed，树变更时重建）算余弦，若最相似类别与 LLM 所选类别不一致，则置信度减半压回待审区——两路独立证据一致才自动移动；向量路不可用（embed 失败/余弦并列无区分度）时旁路，按纯 LLM 判定。
- **FR-2 置信度分流**：`confidence ≥ 0.85` → 自动移动到类别目录；`0.5 ≤ confidence < 0.85` → 移入 `仓库/待分类/` 并进入待审队列；`confidence < 0.5` 或无可选类别 → 同样移入待分类目录，状态 UNKNOWN。阈值 GUI 可调，0.85/0.5 为默认占位。
- **FR-3 全仓库重排**：目录结构由 LLM 说了算。仓库终态 = `仓库/一级类别/二级类别/文件`，最深 2 级。手动目录全部拆散。`.xunwen/` 与 `待分类/` 不参与重排。
- **FR-4 批次回滚**：每次移动记录 `source→target` 到 `.xunwen/operations.jsonl`（含 batchId）。支持单条撤销与整批次逆序回滚。重排任务 = 一个批次，回滚完全还原重排前结构。
- **FR-5 重名冲突**：目标目录同名文件先比 SHA-256——相同则判定重复副本，跳过移动（保留原处）；不同则目标命名为 `名字 (2).ext` 递增序号。
- **FR-6 类别树**：最多 2 级。初始树由 LLM 冷启动生成（用户批准）。之后 LLM 可提议新类别；提议若与现有类别名 embedding 余弦相似度 > 0.85 → 拒绝提议、文件归入该现有类别；提议之间余弦相似度 > 0.85 → 自动聚合为一个待审项。批准后入树并触发相关文件归位。删除类别 → 其下文件标记待重分类。
- **FR-7 内容提取**：Apache Tika 提取 pdf/docx/xlsx/pptx/txt/md，上限 100k 字符。无文本层（如扫描 PDF）或不可读内容（zip/exe）→ 用文件名 + 扩展名兜底分类，置信度上限压到待审区。**v1 无 OCR、无音视频转写**。
- **FR-8 混合检索**：BM25（smartcn 中文分词）+ KNN 向量（HNSW，存 Lucene 文档字段）RRF 融合（`score = Σ 1/(60 + rank)`），结果含高亮片段。默认搜当前仓库，可切换全部仓库联合检索（结果标注所属仓库）。纯检索，无 RAG 问答。
- **FR-9 多仓库**：配置为仓库列表（`~/.xunwen/repos.json`）；每仓库独立类别树 + 独立索引；**索引与元数据存于各仓库的 `.xunwen/` 目录**，随仓库走、删仓库即删索引。
- **FR-10 LLM 接入**：OpenAI 兼容协议（`/v1/chat/completions`、`/v1/embeddings`），一个 HTTP 客户端通吃 Ollama/vLLM/DeepSeek/GLM。默认 `http://localhost:11434/v1`。全局配置存 `~/.xunwen/config.json`：base-url、api-key（可空）、chat 模型、embedding 模型、向量维度、阈值、并发。
- **FR-11 监视**：GUI 打开期间 WatchService 递归监视；文件写入稳定性检测（size+mtime 连续 2 次采样不变且距最后修改 > 2s 才处理）；工具自身移动产生的事件通过回环过滤忽略。
- **FR-12 索引同步**：文件移动/改名/修改/删除后，扫描 diff 以文件系统为准修正索引（指纹 = sha256/mtime/size）。文档字段含路径、名称、类别、状态、内容、向量。

## 非目标（v2 及以后）

RAG 问答 · 图片 OCR · 音视频转写 · 常驻托盘后台 · 开机自启 · 类别树导入（YAML 手写兜底能力由可编辑的 categories.yaml 天然具备）· jlink/jpackage 安装包

## 技术栈

Java 25 · JavaFX 27（非模块化 classpath 启动，Launcher 模式）· Lucene 10.5.2（core + highlighter + queryparser + analysis-smartcn；KNN 向量为 core 内置 `KnnFloatVectorField`，**无外挂向量库**）· Apache Tika 4.1.0 · Jackson 3.2.4（`tools.jackson.*`，JSON + YAML）· JDK HttpClient · JUnit 5.12 · Maven · Spotless（google-java-format，`mvn verify` 强制）

**跨平台**：macOS / Windows / Linux 均在范围内。索引内相对路径统一 POSIX 风格；全局配置目录 `~/.xunwen` 用 `user.home` 解析；Windows 文件占用导致的移动失败按「跳过并记日志」处理，不中断批任务。

## 数据布局

```
~/.xunwen/
  config.json          # 全局配置
  repos.json           # 仓库路径列表

<仓库>/
  .xunwen/
    index/             # Lucene 索引目录
    categories.yaml    # 类别树（可手改）
    operations.jsonl   # 操作日志（batchId 分组）
  待分类/               # 低置信/未分类文件的物理暂存区（工具管理，非类别节点）
  <一级类别>/
    <二级类别>/
      文件
```

## 关键常量

| 常量 | 值 |
|---|---|
| 自动移动阈值 | 0.85 |
| 待审阈值下限 | 0.5 |
| 相似拒绝/聚合余弦阈值 | 0.85 |
| 提取上限 | 100,000 字符 |
| 分类用内容预览 | 3,000 字符 |
| embedding 用文本 | 前 4,000 字符 |
| 写入稳定窗口 | 2 秒，连续 2 次采样 |
| 默认向量维度 | 1024（bge-m3） |
| 默认分类并发 | 2 |
| 冷启动树约束 | 顶层 ≤ 6、每级子类 ≤ 6、必含「其他」、名称 2–6 字 |
| RRF k | 60 |
| 忽略文件 | `~$*`、`.DS_Store`、`.` 开头隐藏文件、`.xunwen/` |
